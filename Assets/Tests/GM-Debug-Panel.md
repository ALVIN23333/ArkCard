# GM 调试面板使用文档

GM 调试面板是一个**运行时悬浮面板**（IMGUI OnGUI 绘制），用于快速搭建对局场景、调整数值和加速手工测试。它由 `Assets/Scripts/Manager/GMCheatPanel.cs` 实现，仅在 `UNITY_EDITOR || DEVELOPMENT_BUILD` 下编译，不会进入正式构建。

## 打开方式

- 进入 Play 模式后面板**自动创建**（`RuntimeInitializeOnLoadMethod`），无需修改场景。
- 面板是 `DontDestroyOnLoad` 对象：点击结算面板的“重新开始”或任何场景重载后**仍然可用**，无需重新进入 Play。
- 按 **F1** 打开/关闭面板（需要 Game 视图处于焦点）。

## 快捷键一览

| 快捷键 | 功能 |
| --- | --- |
| `F1` | 开关面板 |
| `F2` | 直接结束当前回合 |
| `F3` | 循环时间倍率：1 → 2 → 3 → 1 |
| `F4` | 切换跳过动画（瞬时完成） |
| `F5` | 切换主玩家 AI 托管 |

输入文本框处于编辑状态时快捷键会被屏蔽（`GUIUtility.keyboardControl != 0`），避免打字误触。

## 面板功能

### 目标玩家

顶部的 `我方 / 敌方` 工具栏决定后续操作作用于哪个玩家。切换玩家时，生命/费用输入框会自动同步为该玩家的当前值。

### 设置生命/费用

输入 `当前生命`、`最大生命`、`当前费用`、`最大费用` 后点击 `应用生命/费用`。

- 底层调用 `PlayerController.SetHealth / SetMaxHealth / SetCost / SetMaxCost`，会同步刷新血量/费用 UI。
- 生命与费用均允许**任意非负值**；`最大费用` 不再受 `GameConst.costMax`（10）限制，便于测试高费/超模场景。
- 切换目标玩家时，四个输入框会自动同步为该玩家的当前值。

### 发指定卡牌

1. 在卡牌**滑动窗口**中选择一张卡（网格区域固定高度、可滚动，显示 `index 名称`，数据来自 `CardListSO`）。
2. 可使用 `查找` 输入框快速过滤：按卡名（支持中文）或 `index` 数字匹配。例如输入 `110` 只显示 1101–1106，输入 `抽卡` 显示对应法术；点 `清除` 恢复全部卡牌。
2. 输入数量（1–20，默认 1）。
3. 点击 `发牌`，卡牌会实例化并加入**目标玩家的手牌**（敌方卡牌显示卡背）。

### 填满场地 / 清空场地

- `填满场地`：从卡库随机选取随从卡，填到目标玩家场地上限（`GameConst.fieldMax` = 5）。
- `清空场地`：把目标玩家场上的卡全部送入墓地（`SendCardToGraveyard`）。

### 直接结束当前回合

点击 `直接结束当前回合 (F2)` 或按 F2。以下情况会被拒绝并在日志区提示：

- 游戏已结束
- 回合转换中（`IsTurnTransitioning`）
- 效果结算中（`EffectManager.IsProcessingEffects`）
- 当前玩家不在回合中

### 时间倍率

- 提供 `0.25 / 0.5 / 1 / 2 / 3 / 5` 按钮与 `暂停(0)`。
- 直接设置 `Time.timeScale`，影响 `WaitForSeconds` 协程与 PrimeTween 动画（均使用缩放时间）。
- `timeScale = 0` 相当于暂停：协程与动画冻结，但面板本身（Update/OnGUI）仍可操作，可用来暂停观察战况。

### 跳过动画（瞬时完成）

切换 `AnimeManager.Instant` 全局开关：

- `Delay` 立即执行回调；
- 各类位移/缩放/旋转直接落位，不再创建 tween；
- 攻击/触发动画直接恢复原始姿态并**同步触发完成回调**（伤害结算不会丢失）。

开启后游戏节奏会显著加快，适合快速验证逻辑；关闭后恢复原动画表现。

### 主玩家 AI 托管

开启后创建/启用 `AutoPlayDriver` 组件：主玩家回合自动执行 MCTS 规划出的动作（与敌方 `AIController` 独立，互不影响）。关闭后主玩家恢复人工操作。

`AutoPlayDriver` 同样是 `DontDestroyOnLoad` 对象：重开场景后托管状态保持，不需要重新开启。

## 日志区

面板底部显示最近 30 条操作日志（时间戳 + 结果），用于确认每次操作是否生效及被拒绝的原因。

## 依赖的代码变更

- `PlayerController.SetHealth / SetMaxHealth / SetCost / SetMaxCost`：调试 setter，刷新 UI（费用允许任意非负值）。
- `AnimeManager.Instant`：瞬时动画开关。
- `AutoPlayDriver`：主玩家托管组件（`AutoPlayDriver.GetOrCreate()` 获取实例）。

## 常见问题

- **快捷键按了没反应**：确认 Game 视图有键盘焦点；面板快捷键只在 Play 模式下生效。
- **发牌后敌方看不到卡面**：敌方手牌按规则显示卡背，属正常表现。
- **结束回合按钮无反应**：查看面板日志区，通常是回合转换中或效果结算中。
- **重开场景后找不到面板**：面板与 AI 托管组件都是 `DontDestroyOnLoad`，正常情况下重载场景后仍存在；若完全退出 Play 再进入，会自动重新创建。
